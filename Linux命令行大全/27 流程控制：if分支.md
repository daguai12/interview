### 核心概念：命令的“退出状态” (Exit Status)

在详细介绍语法之前，您必须理解 Shell 的一个核心概念：**Shell 不关心“布尔值”（True/False），它只关心“命令的退出状态”。**

  * 在 Shell 中，**`0` 代表“成功”（True）**。
  * **任何非 `0` 的值（如 `1`, `2`, `127` 等）都代表“失败”（False）**。
  * 每个命令执行后，都会有一个退出状态码，存储在特殊变量 `$?` 中。

`if` 语句检查的就是紧跟在它后面的**命令**的退出状态码。

```bash
# 这是一个成功的命令，退出状态为 0
ls /home
echo $?  # 输出 0

# 这是一个失败的命令，退出状态非 0
ls /non_existent_directory
echo $?  # 输出一个非 0 值（例如 2）
```

`if` 语句的逻辑就是：

  * `if [ ... ]` -\> 如果 `[ ... ]` 这个命令的退出状态是 `0`（成功），则...
  * `if ls /some/file` -\> 如果 `ls /some/file` 这个命令的退出状态是 `0`（即文件存在且可读），则...

### 1\. `if` 语句（条件分支）

`if` 是最基本的分支结构。

#### 1.1. 语法结构

**基本语法 (if-then-fi):**

```bash
if [ condition ]
then
    # 如果 condition 为真（退出状态为 0），执行这里的命令
    command1
    command2
fi
```

  * `fi` 是 `if` 的反写，表示 `if` 块的结束。

**if-else 语法 (if-then-else-fi):**

```bash
if [ condition ]
then
    # condition 为真 (0) 时执行
    command_if_true
else
    # condition 为假 (非 0) 时执行
    command_if_false
fi
```

**if-elif-else 语法 (多重分支):**

```bash
if [ condition1 ]
then
    # condition1 为真 (0) 时执行
    command1
elif [ condition2 ]
then
    # condition1 为假 (非 0)，且 condition2 为真 (0) 时执行
    command2
else
    # 以上所有条件都为假 (非 0) 时执行
    command_else
fi
```

#### 1.2. 条件测试：`[ ]` vs `[[ ]]`

`if` 后面跟的 `[ ... ]` 到底是什么？

  * `[ ]`：这是 `test` 命令的简写。`[ "$a" = "$b" ]` **等价于** `test "$a" = "$b"`。它是一个**命令**。
  * `[[ ]]`：这是 Bash、Zsh 等现代 Shell 内置的**关键字**。它不是一个命令。

> **⚠️ 强烈建议：** 在编写 Bash 或 Zsh 脚本时，**始终优先使用 `[[ ]]`**。它更健壮、功能更强，且不易出错。

**为什么 `[[ ]]` 更好？**

1.  **变量引用：** 在 `[ ]` 中，如果变量可能为空或包含空格，**必须**使用双引号（如 `[ "$var" = "hello" ]`）。如果不加，`[ $var = "hello" ]` 在 `$var` 为空时会变成 `[ = "hello" ]`，导致语法错误。
2.  **`[[ ]]` 的健壮性：** `[[ ]]` 内部会阻止“词语分裂”（Word Splitting），所以 `[[ $var = "hello" ]]` 即使 `$var` 为空或含空格也能正常工作。
3.  **高级功能：** `[[ ]]` 支持更直观的 `&&`（与）、`||`（或），以及模式匹配（Globbing）和正则表达式（Regex）。

#### 1.3. `[ ]` 和 `[[ ]]` 内部的常用测试操作符

**1. 字符串比较**

| 操作符 | `[ ]` (test) | `[[ ... ]]` | 描述 |
| :--- | :--- | :--- | :--- |
| **等于** | `"$s1" = "$s2"` | `"$s1" == "$s2"` | 字符串内容相同。`[[` 也支持 `=`，但 `==` 更清晰。 |
| **不等于** | `"$s1" != "$s2"` | `"$s1" != "$s2"` | 字符串内容不同。 |
| **小于** | `"$s1" \< "$s2"` | `"$s1" < "$s2"` | 字符串按字典序小于（注意 `[ ]` 中 `<` 需转义）。 |
| **大于** | `"$s1" \> "$s2"` | `"$s1" > "$s2"` | 字符串按字典序大于（注意 `[ ]` 中 `>` 需转义）。 |
| **非空** | `-n "$s1"` | `-n "$s1"` | 字符串长度非 0。 |
| **为空** | `-z "$s1"` | `-z "$s1"` | 字符串长度为 0。 |
| **正则** | (不支持) | `"$s1" =~ REGEX` | `[[ "hello" =~ ^h.l+$ ]]` (Bash 3.0+)。 |
| **通配符** | (不支持) | `"$s1" == *.txt` | `[[ "file.txt" == *.txt ]]` (Glob 模式匹配)。 |

**2. 整数比较（非常重要！）**

在 Shell 中，**`=` 和 `!=` 用于字符串比较**。整数比较必须使用特定的操作符：

| 操作符 | 描述 | 示例 |
| :--- | :--- | :--- |
| `-eq` | (Equal) 等于 | `[ "$num" -eq 10 ]` |
| `-ne` | (Not Equal) 不等于 | `[ "$num" -ne 10 ]` |
| `-gt` | (Greater Than) 大于 | `[ "$num" -gt 10 ]` |
| `-ge` | (Greater or Equal) 大于等于 | `[ "$num" -ge 10 ]` |
| `-lt` | (Less Than) 小于 | `[ "$num" -lt 10 ]` |
| `-le` | (Less or Equal) 小于等于 | `[ "$num" -le 10 ]` |

> **⚠️ 陷阱：** 如果你写 `[ "5" > "10" ]`，Shell 会执行**字符串比较**（"5" 在字典序上大于 "1"），结果为真。正确的整数比较是 `[ "5" -gt "10" ]`，结果为假。

**3. 文件测试**

| 操作符 | 描述 | 示例 |
| :--- | :--- | :--- |
| `-e file` | (Exists) 文件或目录存在 | `[ -e "/etc/hosts" ]` |
| `-f file` | (File) 是一个常规文件 | `[ -f "/etc/hosts" ]` |
| `-d dir` | (Directory) 是一个目录 | `[ -d "/etc" ]` |
| `-s file` | (Size) 文件存在且大小不为 0 | `[ -s "/etc/hosts" ]` |
| `-r file` | (Readable) 文件可读 | `[ -r "/etc/hosts" ]` |
| `-w file` | (Writable) 文件可写 | `[ -w "/etc/hosts" ]` |
| `-x file` | (Executable) 文件可执行 | `[ -x "/bin/ls" ]` |
| `file1 -nt file2` | (Newer Than) file1 比 file2 新 | `[ "a.txt" -nt "b.txt" ]` |
| `file1 -ot file2` | (Older Than) file1 比 file2 旧 | `[ "a.txt" -ot "b.txt" ]` |

**4. 逻辑操作符**

| `[ ]` (旧式) | `[[ ]]` (推荐) | 描述 |
| :--- | :--- | :--- |
| `! condition` | `! condition` | 逻辑非 (NOT) |
| `cond1 -a cond2` | `cond1 && cond2` | 逻辑与 (AND) |
| `cond1 -o cond2` | `cond1 || cond2` | 逻辑或 (OR) |

> **提示：** 在 `[ ]` 中使用 `-a` 和 `-o` 是**不被推荐的**，它们很容易出错。
> 推荐的做法是使用 `&&` 和 `||` **连接** `test` 命令：
> `if [ "$a" -gt 10 ] && [ "$b" -lt 5 ]; then ...`
>
> 或者，使用 `[[ ]]`（最佳实践）：
> `if [[ "$a" -gt 10 && "$b" -lt 5 ]]; then ...`

#### 1.4. 示例

```bash
#!/bin/bash

# 变量定义
user="admin"
count=5
file_path="/etc/passwd"

# 示例 1: 字符串比较 (使用 [[ ]])
if [[ "$user" == "admin" ]]; then
    echo "欢迎管理员。"
fi

# 示例 2: 整数比较 (if-else)
if [[ "$count" -lt 10 ]]; then
    echo "数量 ($count) 小于 10。"
else
    echo "数量 ($count) 大于等于 10。"
fi

# 示例 3: 文件测试 (if-elif-else)
if [[ ! -e "$file_path" ]]; then
    echo "错误: 文件 $file_path 不存在。"
elif [[ -d "$file_path" ]]; then
    echo "错误: $file_path 是一个目录，不是文件。"
elif [[ -r "$file_path" ]]; then
    echo "$file_path 可读。"
else
    echo "$file_path 不可读。"
fi

# 示例 4: 复杂的逻辑与 (&&)
if [[ "$user" == "admin" && "$count" -gt 3 ]]; then
    echo "管理员 $user 拥有超过 3 个权限。"
fi

# 示例 5: 正则表达式 (Bash 特有)
email="user@example.com"
if [[ "$email" =~ ^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$ ]]; then
    echo "Email 地址格式正确。"
else
    echo "Email 地址格式错误。"
fi
```

### 2\. `case` 语句（多路分支）

当你需要根据一个变量的多种**固定值**（尤其是字符串）来进行分支时，`case` 语句比 `if-elif` 更清晰、更高效。它类似于 C 语言中的 `switch`。

#### 2.1. 语法结构

```bash
case "$variable" in
    pattern1)
        # 匹配 pattern1 时执行
        command_list_1
        ;;  # (重要：使用双分号结束)

    pattern2|pattern3)
        # 匹配 pattern2 或 pattern3 时执行
        command_list_2
        ;;

    *.txt)
        # 匹配所有以 .txt 结尾的字符串 (支持通配符)
        command_list_3
        ;;

    *)
        # (默认) 匹配以上所有模式之外的任何内容
        command_default
        ;;
esac
```

  * `esac` 是 `case` 的反写，表示 `case` 块的结束。
  * `;;` 类似于 C 的 `break`，它表示这个分支的结束，防止“穿透”到下一个分支。

#### 2.2. `case` 示例

`case` 语句非常适合处理脚本的命令行参数（如 `-a`, `-b`, `-c`）或用户交互（如 "yes/no"）。

```bash
#!/bin/bash

# 示例 1: 处理用户输入
read -p "您确定要继续吗? (yes/no/cancel): " answer

case "$answer" in
    # 匹配 'yes' 或 'y' (忽略大小写, 使用 |)
    [Yy]|[Yy][Ee][Ss])
        echo "正在继续..."
        ;;

    # 匹配 'no' 或 'n' (忽略大小写)
    [Nn]|[Nn][Oo])
        echo "操作已取消。"
        exit 1
        ;;
    
    # 匹配 'cancel' (精确匹配)
    cancel)
        echo "操作已取消。"
        exit 1
        ;;

    # 默认分支
    *)
        echo "无效输入 '$answer'。"
        exit 2
        ;;
esac
```

```bash
#!/bin/bash

# 示例 2: 检查文件类型
filename="document.pdf"

case "$filename" in
    *.txt|*.md)
        echo "$filename 是一个文本文档。"
        ;;
    
    *.jpg|*.png|*.gif)
        echo "$filename 是一个图像文件。"
        ;;

    *.pdf)
        echo "$filename 是一个 PDF 文件。"
        ;;
    
    *)
        echo "未知文件类型: $filename"
        ;;
esac
```

### 3\. 逻辑与 (&&) 和 逻辑或 (||)

在 Shell 中，`&&` 和 `||` 也可以作为一种简写的“分支”来使用。它们是**短路操作符**。

  * `command1 && command2`：**只有** `command1` 成功（`$?` 为 0）时，**才**会执行 `command2`。
  * `command1 || command2`：**只有** `command1` 失败（`$?` 非 0）时，**才**会执行 `command2`。

#### 3.1. 示例

这在需要“如果成功则...”或“如果失败则...”的简单场景中非常有用。

```bash
# 替代 if [ -d "logs" ]; then mkdir "logs"; fi
# 检查 "logs" 目录是否存在，如果不存在 (||)
[ -d "logs" ] || mkdir "logs"
echo "---"

# 替代 if [ -f "app.log" ]; then rm "app.log"; fi
# 检查 "app.log" 是否存在，如果存在 (&&)
[ -f "app.log" ] && rm "app.log"
```

### 4\. 循环结构（`for`, `while`, `until`）

虽然您主要问的是“分支”，但流程控制也包含循环。这里简要介绍一下。

#### 4.1. `for` 循环（遍历列表）

`for` 循环用于遍历一个**列表**（如文件名、数字序列、字符串）。

```bash
# 遍历字符串列表
for user in alice bob charlie
do
    echo "正在处理用户: $user"
done

# 遍历文件名 (使用通配符)
for file in /var/log/*.log
do
    if [[ -s "$file" ]]; then # 检查文件是否非空
        echo "$file 是一个非空日志文件。"
    fi
done

# 遍历数字序列 (Bash)
for i in {1..5}
do
    echo "数字: $i"
done
```

#### 4.2. `while` 循环（条件为真时循环）

`while` 循环在\*\*条件为真（命令退出状态为 0）\*\*时持续执行。

```bash
# 计数器
count=1
while [[ "$count" -le 5 ]]
do
    echo "Count: $count"
    # (( ... )) 是 Shell 中进行算术运算的推荐方式
    ((count++)) 
done
```

`while` 的一个经典用途是**逐行读取文件**：

```bash
file_to_read="users.txt"
while read -r line
do
    echo "从文件中读取到: $line"
done < "$file_to_read" # 使用输入重定向
```

#### 4.3. `until` 循环（条件为假时循环）

`until` 是 `while` 的反向。它在\*\*条件为假（命令退出状态非 0）\*\*时持续执行。

```bash
# 等待服务启动 (模拟)
count=0
until ((count > 5)) # 直到 count > 5 (为真) 时停止
do
    echo "等待服务启动... ($count)"
    sleep 1
    ((count++))
done
echo "服务已“启动”。"
```

#### 4.4. 循环控制 `break` 和 `continue`

  * `break`：立即跳出**当前**循环（`for`, `while`, `until`）。
  * `continue`：跳过本次循环的剩余命令，直接进入下一次循环。

<!-- end list -->

```bash
for i in {1..10}
do
    if [[ "$i" -eq 3 ]]; then
        continue # 跳过 3
    fi
    
    if [[ "$i" -eq 8 ]]; then
        break # 遇到 8，停止循环
    fi
    
    echo $i
done
# 输出: 1 2 4 5 6 7
```

### 总结：关键点和最佳实践

1.  **`if` 检查的是 `$?`：** 0 为真（成功），非 0 为假（失败）。
2.  **优先使用 `[[ ]]`：** 它更安全、功能更强。
3.  **`[ ]` 中要小心：**
      * `[` 后面和 `]` 前面必须有空格：`[ "$a" = "$b" ]`。
      * 所有变量引用**必须**加双引号：`[ "$var" ... ]`。
4.  **整数和字符串比较不同：**
      * 整数：`-eq`, `-ne`, `-gt`, `-lt`...
      * 字符串：`==` (或 `=`), `!=`, `<` (字典序)...
5.  **`case` 语句：** 非常适合处理多个固定的字符串匹配，用 `;;` 结束分支。
6.  **`&&` 和 `||`：** 可用于编写简洁的“如果成功/失败则...”的单行命令。

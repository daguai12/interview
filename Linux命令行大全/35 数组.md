您好！数组是 Shell 脚本中（特别是 Bash）用来存储和管理“一组相关数据”的强大工具。它比使用一堆单独的变量（如 `file1`, `file2`, `file3`）要高效和灵活得多。

我将为您详细讲解 Shell 数组，主要集中在 **Bash** shell 中，因为它是事实上的标准。

-----

### 🔔 重要前提：`sh` (POSIX) vs `bash`

首先，一个**极其重要**的区别：

  * **`/bin/sh` (标准的 POSIX shell)**：**不支持**我们通常所说的数组（`my_array=(...)` 这种语法）。它唯一类似数组的结构是“位置参数”（`$@`，即 `$1`, `$2`, ...）。
  * **`/bin/bash` (以及 `zsh`, `ksh`)**：**完全支持**数组。

> **最佳实践：** 如果您要在脚本中使用数组，**必须**使用 `#!/bin/bash`（或 `#!/usr/bin/env bash`）作为您的 shebang（脚本第一行），**绝对不能**用 `#!/bin/sh`。

Bash 支持两种类型的数组：

1.  **索引数组 (Indexed Arrays)**：使用数字索引（0, 1, 2...）访问，这是最常用的类型。
2.  **关联数组 (Associative Arrays)**：使用字符串“键”（Key）访问（也称为 Maps 或 Dictionaries）。(Bash 4.0+ 支持)

-----

### 第一部分：索引数组 (Indexed Arrays)

这是最常见的数组形式。索引从 `0` 开始。

#### 1.1. 声明和初始化数组

有多种方法可以定义一个索引数组：

**方法 1：一次性赋值（推荐）**
使用圆括号 `()`，元素间用空格分隔。

```bash
# 元素可以是数字、字符串，或包含空格（需用引号）
my_array=(10 "hello" "Third Element" 99.5)
```

**方法 2：逐个赋值**

```bash
files[0]="file.txt"
files[1]="document.log"
files[2]="/etc/hosts"
```

**方法 3：稀疏数组 (Sparse Arrays)**
您可以跳过索引，Bash 允许“稀疏”数组（即索引不连续）。

```bash
sparse_array[0]="first"
sparse_array[5]="sixth"
# 索引 1, 2, 3, 4 并未设置
```

**方法 4：从命令输出创建（不推荐用于文件）**

```bash
# 警告：这种方式在文件名包含空格时会出错！
files_list=($(ls /etc))
```

**方法 5：从通配符创建（推荐用于文件）**
这是一种更安全、更健壮的获取文件列表的方式。

```bash
# 将当前目录下所有的 .log 文件放入数组
log_files=(*.log)
```

#### 1.2. 访问数组元素

访问数组需要使用花括号 `{}`。

**1. 访问单个元素**
语法：`${array_name[index]}`

```bash
my_array=("apple" "banana" "cherry")

echo "第一个元素: ${my_array[0]}" # 输出: apple
echo "第二个元素: ${my_array[1]}" # 输出: banana
echo "第三个元素: ${my_array[2]}" # 输出: cherry

# 访问不存在的索引，不会报错，而是返回空字符串
echo "第五个元素: ${my_array[4]}" # 输出: (空)

# Bash 4.3+ 支持负数索引 (从末尾访问)
echo "最后一个元素: ${my_array[-1]}" # 输出: cherry
```

**2. 访问所有元素 (核心重点！)**
这是初学者最容易出错的地方。请仔细区分 `*` 和 `@`。

  * **`$my_array`**：**（错误！）** 这等同于 `${my_array[0]}`，只返回**第一个**元素。
  * **`"${my_array[*]}"`**：将所有元素合并成**一个**单独的字符串，元素间用 `$IFS` 的第一个字符（默认为空格）分隔。
  * **`"${my_array[@]}"`**：**（推荐！）** 这是最安全、最常用的方式。它会将每个元素扩展为**独立**的、带引号的字符串。`"$1" "$2" "$3" ...`

**演示 `*` 和 `@` 的区别：**

```bash
my_array=("file 1.txt" "file 2.log" "file 3")

echo "--- 使用 [@] (正确) ---"
for item in "${my_array[@]}"
do
    echo "项: $item"
done

echo
echo "--- 使用 [*] (合并) ---"
for item in "${my_array[*]}"
do
    echo "项: $item"
done
```

**输出：**

```
--- 使用 [@] (正确) ---
项: file 1.txt  <-- (保留了空格，3个独立的项)
项: file 2.log
项: file 3

--- 使用 [*] (合并) ---
项: file 1.txt file 2.log file 3  <-- (所有元素合并成了1个项)
```

> **最佳实践：** 除非您有特殊目的，否则请**始终使用 `"${my_array[@]}"`** 来访问或遍历所有元素。

#### 1.3. 获取数组信息（长度和索引）

**1. 获取数组长度（元素个数）**
语法：`${#array_name[@]}`

```bash
my_array=("apple" "banana" "cherry")
echo "数组长度: ${#my_array[@]}" # 输出: 3

sparse_array[0]="a"
sparse_array[5]="b"
echo "稀疏数组长度: ${#sparse_array[@]}" # 输出: 2 (只计算已设置的元素)
```

**2. 获取单个元素的长度**
语法：`${#array_name[index]}`

```bash
my_array=("apple" "banana" "cherry")
echo "第一个元素的长度: ${#my_array[0]}" # 输出: 5 (apple的长度)
```

**3. 获取所有索引（键）**
语法：`${!array_name[@]}`
这对于遍历稀疏数组或关联数组至关重要。

```bash
sparse_array[0]="a"
sparse_array[5]="b"
sparse_array[10]="c"
echo "稀疏数组的索引: ${!sparse_array[@]}" # 输出: 0 5 10
```

#### 1.4. 修改和删除数组元素

**1. 修改元素**
直接重新赋值即可。

```bash
my_array[1]="blueberry"
echo "${my_array[1]}" # 输出: blueberry
```

**2. 追加元素 (Append)**
这是最简单的方法：

```bash
my_array=("a" "b")
my_array+=("c" "d")
echo "${my_array[@]}" # 输出: a b c d
```

也可以按索引追加：

```bash
# 获取下一个索引 (即当前长度)
my_array[${#my_array[@]}]="new_last_item"
```

**3. 删除元素 (unset)**
`unset` 会从数组中**移除**一个元素（使其成为稀疏数组），而不是将其设置为空字符串。

```bash
my_array=("a" "b" "c" "d")
unset my_array[1] # 删除 "b"

echo "所有元素: ${my_array[@]}"  # 输出: a c d
echo "所有索引: ${!my_array[@]}" # 输出: 0 2 3 (索引1消失了)
echo "数组长度: ${#my_array[@]}" # 输出: 3
```

**4. 删除整个数组**
`unset array_name`

```bash
unset my_array
```

#### 1.5. 遍历（循环）数组

**方法 1：遍历所有值（推荐）**

```bash
my_array=("apple" "banana" "cherry")
for item in "${my_array[@]}"
do
    echo "元素值: $item"
done
```

**方法 2：遍历所有索引（适用于稀疏数组）**

```bash
sparse_array[0]="a"
sparse_array[5]="b"
for index in "${!sparse_array[@]}"
do
    echo "索引 $index 上的值是: ${sparse_array[$index]}"
done
```

**输出：**

```
索引 0 上的值是: a
索引 5 上的值是: b
```

**方法 3：C 风格循环（不推荐用于稀疏数组）**

```bash
my_array=("a" "b" "c")
length=${#my_array[@]}

for (( i=0; i<$length; i++ ))
do
    echo "索引 $i 上的值是: ${my_array[$i]}"
done
# 警告：如果数组是稀疏的 (unset my_array[1])，这将失败！
```

#### 1.6. 数组切片 (Slicing)

语法：`${array_name[@]:offset:length}`

```bash
my_array=("a" "b" "c" "d" "e")

# 从索引 1 开始，取 2 个元素
echo "${my_array[@]:1:2}" # 输出: b c

# 从索引 2 开始，取所有剩余元素
echo "${my_array[@]:2}"   # 输出: c d e
```

### 第二部分：关联数组 (Associative Arrays - Bash 4.0+)

关联数组使用字符串作为“键”（Key），就像 Python 的字典或 C++ 的 `std::map`。

#### 2.1. 声明（必须！）

使用关联数组**必须**先用 `declare -A` 显式声明。

```bash
# 必须先声明
declare -A user_info
```

  * `declare -A`：(Associative)
  * `declare -a`：(Array) 也可以用于声明索引数组，但索引数组通常不需要显式声明。

#### 2.2. 赋值

**方法 1：逐个赋值**

```bash
declare -A user_info
user_info["name"]="Alice"
user_info["uid"]="1001"
user_info["shell"]="/bin/bash"
user_info["home_dir"]="/home/alice"
```

**方法 2：一次性赋值**

```bash
declare -A ports=( [http]=80 [https]=443 [ssh]=22 )
```

#### 2.3. 访问

语法与索引数组类似，但索引是字符串。

```bash
echo "用户名: ${user_info["name"]}"       # 输出: Alice
echo "HTTP 端口: ${ports[http]}"         # 输出: 80

# 键也可以是变量
key="uid"
echo "用户 ID: ${user_info[$key]}"        # 输出: 1001
```

#### 2.4. 遍历（循环）

遍历关联数组时，你几乎总是想遍历**键（Key）**。

```bash
declare -A ports=( [http]=80 [https]=443 [ssh]=22 )

# ${!ports[@]} 会返回所有的键 (http https ssh)
echo "服务及其端口:"
for service in "${!ports[@]}"
do
    port=${ports[$service]}
    echo "  - $service 运行在 $port 端口"
done
```

**输出：**

```
服务及其端口:
  - ssh 运行在 22 端口
  - http 运行在 80 端口
  - https 运行在 443 端口
(注意：顺序是不固定的！)
```

#### 2.5. 获取信息和删除

  * **获取所有键：** `${!user_info[@]}`
  * **获取所有值：** `${user_info[@]}`
  * **获取元素个数：** `${#user_info[@]}`
  * **删除一个键值对：** `unset user_info["shell"]`

-----

### 总结：关键点和陷阱

1.  **Shebang 必须是 `#!/bin/bash`**，而不是 `#!/bin/sh`。
2.  **访问单个元素**：始终使用花括号：`${my_array[0]}`。
3.  **访问所有元素**：**永远使用 `"${my_array[@]}"`**。这是最安全、最可靠的方式。
4.  **`$my_array` 的陷阱**：`echo $my_array` 只会打印**第一个**元素。
5.  **关联数组 (Key-Value)**：必须先用 `declare -A` 声明。
6.  **遍历数组**：
      * 索引数组（值）：`for item in "${my_array[@]}"`
      * 索引数组（索引）：`for i in "${!my_array[@]}"`
      * 关联数组（键）：`for key in "${!my_map[@]}"`

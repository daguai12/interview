```cpp
#include <iostream>
#include <vector>
#include <utility> // for std::swap

/**
 * @brief 分区函数 (Lomuto partition scheme)
 * @details 它的工作是：
 * 1. 选定一个基准值 (pivotValue)。
 * 2. 重新排列数组，使得所有小于等于基准的元素在左边，
 * 所有大于基准的元素在右边。
 * 3. 将基准值放在中间的正确位置。
 * * @param array 要分区的向量
 * @param left  子数组的起始索引
 * @param right 子数组的结束索引 (该位置的元素被选为基准)
 * @return 基准值分区后的最终存放索引
 */
int partition(std::vector<int>& array, int left, int right) {
    
    // 1. 选择子数组的最后一个元素作为“基准值”
    int pivotValue = array[right];

    // 2. "smallerElementBoundary" (小元素区域边界)
    //    它追踪“小于等于基准”区域的右边界。
    //    初始化为 'left - 1'，表示该区域目前为空。
    int smallerElementBoundary = (left - 1);

    // 3. 遍历从 'left' 到 'right-1' 的所有元素 (用 currentIndex 追踪)
    for (int currentIndex = left; currentIndex < right; ++currentIndex) {
        
        // 4. 如果当前遍历到的元素 <= 基准值
        if (array[currentIndex] <= pivotValue) {
            
            // ...那么，"小元素区域"需要扩大一格
            smallerElementBoundary++;
            
            // ...并将这个“小元素” (array[currentIndex]) 交换到"小元素区域"的末尾
            std::swap(array[smallerElementBoundary], array[currentIndex]);
        }
        // 如果 array[currentIndex] > pivotValue，我们什么都不做，
        // 只需要移动 currentIndex，这个“大元素”自然就留在了右侧区域。
    }

    // 5. 循环结束，'smallerElementBoundary' 指向最后一个“小元素”
    //    因此，基准值 (pivotValue) 的正确位置是 'smallerElementBoundary + 1'
    //    我们将基准值 (它一直待在 array[right] 位置) 与这个正确位置交换
    std::swap(array[smallerElementBoundary + 1], array[right]);

    // 6. 返回基准值的新索引
    return (smallerElementBoundary + 1);
}

/**
 * @brief 快速排序的主递归函数
 * @param array 要排序的向量
 * @param left  排序范围的起始索引
 * @param right 排序范围的结束索引
 */
void quickSort(std::vector<int>& array, int left, int right) {
    
    // 递归的终止条件：
    // 只有当子数组至少有两个元素时 (left < right)，才需要排序
    if (left < right) {
        
        // 1. 调用分区函数，它会：
        //    a. 重新排列 array[left...right]
        //    b. 返回基准元素所在的最终索引
        int pivotFinalIndex = partition(array, left, right);

        // 2. 递归地对基准“左边”的子数组进行排序
        //    (注意：不包括基准本人)
        quickSort(array, left, pivotFinalIndex - 1);

        // 3. 递归地对基准“右边”的子数组进行排序
        //    (注意：不包括基准本人)
        quickSort(array, pivotFinalIndex + 1, right);
    }
}
```

### 简介的思路讲解

快速排序的思路是\*\*“分而治之” (Divide and Conquer)\*\*。

你可以把它想象成一个“指挥官” (`quickSort` 函数) 和一个“分区工人” (`partition` 函数)。

1.  **指挥官 (`quickSort`) 的任务：**

      * 指挥官接到一个排序任务（比如“排序索引从 0 到 10 的元素”）。
      * **终止条件**：如果任务范围很小（比如“排序索引 5 到 5”），说明只有 1 个或 0 个元素，指挥官就认为任务完成，直接返回。
      * **分配任务**：否则，他会叫来一个“分区工人” (`partition`)，说：“你去把这个范围（0 到 10）给我分区！”
      * **等待结果**：分区工人干完活后，会告诉指挥官：“报告！我把‘基准值’（比如 50）放在了索引 4 的位置上。”
      * **分而治之**：指挥官收到报告后，就把原来的大任务分成了两个小任务，然后**递归地**喊来两个新的指挥官：
        1.  “你，去排序索引 0 到 3 的部分（基准左边）。”
        2.  “你，去排序索引 5 到 10 的部分（基准右边）。”
      * 这个过程不断重复，直到所有子任务都小到（0或1个元素）自动完成。

2.  **分区工人 (`partition`) 的任务：**

      * 这是算法的**核心**。工人的目标是：在接到的范围内（比如 0 到 10），选一个\*\*“基准值”\*\*（`pivotValue`，这里选的是最后一个元素）。
      * 他从左到右遍历这个范围，心里维护着一个\*\*“小元素区域”\*\*（由 `smallerElementBoundary` 标记边界）。
      * 当他看到一个元素**小于等于**基准值时，他就把这个元素扔到“小元素区域”里（通过 `swap` 操作）。
      * 当他看到一个元素**大于**基准值时，他就不管它，继续往前走（这个“大元素”自动留在了后面）。
      * 遍历完成后，他把那个“基准值”本人（它一直被晾在最后）放到“小元素区域”的**正后方**。
      * 最后，他向指挥官报告这个“基准值”的**最终索引**。

`std::map` 是 C++ 标准库中一个非常有用的关联容器，它存储按键排序的键值对（key-value pairs），且键是唯一的。

以下是 `std::map<Key, T, Compare, Allocator>` 的主要成员函数列表，按功能分类：

### 📈 构造、析构和赋值
* `map()`: 构造函数。有多种重载，允许创建空的 `map`、从另一个 `map` 拷贝/移动、从一个范围或初始化列表构造。
* `~map()`: 析构函数，销毁 `map` 中的所有元素。
* `operator=`: 赋值运算符，用另一个 `map` 的内容替换当前 `map` 的内容（同样支持拷贝、移动和初始化列表赋值）。

### 🔍 元素访问
* `operator[]`: 访问指定键（`key`）对应的值（`T&`）。
    > **注意：** 这是一个非常特殊的函数。如果 `key` 不存在，`operator[]` 会**自动插入**一个新元素，键为 `key`，值（`T`）为默认构造。
* `at()`: 访问指定键（`key`）对应的值（`T&`）。
    > 与 `operator[]` 不同，如果 `key` 不存在，`at()` 会**抛出一个 `std::out_of_range` 异常**。

### 🧭 迭代器 (Iterators)
* `begin()` / `cbegin()`: 返回指向 `map` 中第一个元素（按键排序）的迭代器 / 常量迭代器。
* `end()` / `cend()`: 返回指向 `map` 末尾（最后一个元素之后）的迭代器 / 常量迭代器。
* `rbegin()` / `crbegin()`: 返回指向 `map` 中最后一个元素（按键反向排序）的反向迭代器 / 常量反向迭代器。
* `rend()` / `crend()`: 返回指向 `map` 反向末尾（第一个元素之前）的反向迭代器 / 常量反向迭代器。

### 📦 容量 (Capacity)
* `empty()`: 检查 `map` 是否为空（即 `size() == 0`）。
* `size()`: 返回 `map` 中元素的数量。
* `max_size()`: 返回 `map` 理论上能容纳的最大元素数量。

### ✏️ 修改器 (Modifiers)
* `clear()`: 移除 `map` 中的所有元素，使其 `size()` 变为 0。
* `insert()`: 插入新元素。有多种重载：
    * 插入 `std::pair<Key, T>`（或 `value_type`）。
    * 带提示（hint）位置插入，可能更高效。
    * 插入一个范围（例如来自另一个容器的迭代器）。
    * 插入一个初始化列表。
* `insert_or_assign()` (C++17): 插入一个新元素，或者如果键（`key`）已存在，则**更新**该键对应的值。
* `emplace()`: 原地构造元素（直接在 `map` 内部构造 `std::pair`），通常比 `insert()` 更高效。
* `emplace_hint()`: 在提示位置（hint）原地构造元素。
* `try_emplace()` (C++17): 只有当键（`key`）不存在时，才原地构造并插入新元素。如果键已存在，则什么也不做。
* `erase()`: 删除元素。有多种重载：
    * 通过迭代器位置删除。
    * 通过键（`key`）删除。
    * 通过迭代器范围删除。
* `swap()`: 交换两个 `map` 的内容。
* `extract()` (C++17): 提取（移除）包含指定键的节点（`node_handle`），允许在不重新分配内存的情况下移动或修改元素。
* `merge()` (C++17): 将另一个 `map`（或 `multimap`）的节点合并到当前 `map` 中。

### 🔎 查找与观察器 (Lookup & Observers)
* `count()`: 返回具有指定键（`key`）的元素数量。由于 `std::map` 的键是唯一的，返回值永远是 **0 或 1**。
* `find()`: 查找具有指定键（`key`）的元素。
    * 如果找到，返回指向该元素的迭代器。
    * 如果未找到，返回 `end()` 迭代器。
* `contains()` (C++20): 检查 `map` 中是否存在具有指定键（`key`）的元素，返回 `true` 或 `false`。
* `lower_bound()`: 返回指向**不小于**（`>=`）指定键（`key`）的第一个元素的迭代器。
* `upper_bound()`: 返回指向**大于**（`>`）指定键（`key`）的第一个元素的迭代器。
* `equal_range()`: 返回一个 `std::pair`，包含 `lower_bound()` 和 `upper_bound()` 的结果。对于 `std::map`，这定义了键（`key`）在 `map` 中存在的（最多一个）元素的范围。
* `key_comp()`: 返回用于比较键的比较器（`Compare`）副本。
* `value_comp()`: 返回一个用于比较 `value_type`（即 `std::pair`）的比较器副本（它内部会使用 `key_comp` 来比较键）。

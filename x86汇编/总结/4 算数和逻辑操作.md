### 核心总结

该文档将算术和逻辑操作分为四类：
1.  **加载有效地址 (`leaq`)**：一条“伪”算术指令，用于计算内存地址，但经常被编译器用来执行快速的加法和乘法运算。
2.  **一元操作**：只有一个操作数（如 `++`, `--`），例如 `INC`（加 1）、`DEC`（减 1）、`NEG`（取负）。
3.  **二元操作**：有两个操作数（如 `+`, `-`, `&`, `^`），例如 `ADD`（加）、`SUB`（减）、`AND`（与）。
4.  **移位操作**：用于位移（如 `<<`, `>>`），包括 `SAL`/`SHL`（左移）、`SAR`（算术右移）、`SHR`（逻辑右移）。

### 关键知识点讲解

#### 1. `leaq`：最巧妙的指令

`leaq` (Load Effective Address) 是最重要也最特殊的指令之一。

* **字面功能**：加载有效地址。它的语法格式和 `mov` 从内存读取一样，但它**根本不访问内存**。
* **实际动作**：它只是计算出源操作数所指定的**内存地址**，然后把这个**地址值**（一个 64 位整数）存入目的寄存器。
* **为何巧妙（编译器的最爱）**：
    * **用途 1：获取指针**。`leaq 8(%rbp), %rax` 会把 `%rbp+8` 这个地址值本身存入 `%rax`，`%rax` 现在就是一个指针。
    * **用途 2：高效算术**。由于 x86-64 的复杂寻址模式 `Imm(rb, ri, s)`，`leaq` 可以一条指令完成"加法"和"乘法"的组合。

**关键示例**：
假设寄存器 `%rdx` 的值是 `x`。
执行指令：`leaq 7(%rdx, %rdx, 4), %rax`
1.  CPU 计算地址：`7 + R[%rdx] + R[%rdx] * 4`
2.  代入 `x`：`7 + x + 4*x`
3.  结果：`5x + 7`
4.  CPU 将 `5x + 7` 这个**计算结果**存入 `%rax` 寄存器。

文档中的 `scale` 函数示例展示了编译器如何用三条 `leaq` 指令实现 `x + 4*y + 12*z`。

#### 2. 一元与二元操作

* **一元操作 (Unary)**：
    * 只有一个操作数，既是源也是目的。
    * 例如 `incq (%rsp)`，会将栈顶内存中的值读出、加 1、再写回。
    * 指令：`INC` (加 1), `DEC` (减 1), `NEG` (取负), `NOT` (位求反)。

* **二元操作 (Binary)**：
    * 有两个操作数：`指令 源, 目的`。
    * **执行效果**：`目的 = 目的 op 源`。
    * **关键易混点（减法）**：`subq %rax, %rdx`
        * **含义**：`%rdx = %rdx - %rax`。
        * **记忆技巧**：可以读作“从 `目的` 中减去 `源`”。
    * 源操作数可以是立即数、寄存器或内存；目的操作数可以是寄存器或内存。

#### 3. 移位操作（`SHL`, `SHR`, `SAR`）

移位操作用于移动二进制位。

* **移位量 (`k`)**：可以有两种指定方式：
    1.  一个立即数（如 `$4`）。
    2.  一个特定的 8 位寄存器：**`%cl`**。

* **左移：`SAL` / `SHL`**
    * `SAL` 和 `SHL` 效果完全相同。
    * 它们都执行**逻辑左移**：向左移动，右边空出的位用 `0` 填充。

* **右移：`SHR` vs `SAR`（重要）**
    * 这是区分 C 语言中**无符号数**和**有符号数**右移的关键。
    * **`SHR` (逻辑右移)**：向右移动，左边空出的位**总是用 `0` 填充**。用于**无符号数**。
    * **`SAR` (算术右移)**：向右移动，左边空出的位用**符号位**（原始数据的最高位）填充。这能保持有符号数的正负不变，用于**有符号数**。

#### 4. `arith` 函数示例分析

文档中的 `arith` 函数展示了这些指令如何协同工作：
C 代码（修正后）：`long t2 = z * 48;`
汇编实现：
1.  `leaq (%rdx, %rdx, 2), %rax`：`%rax = z + 2*z = 3*z`。
2.  `salq $4, %rax`：`%rax = %rax << 4`，即 `%rax = (3*z) * 16 = 48*z`。
这再次证明了编译器喜欢用 `leaq` 和移位指令来代替昂贵的 `imul` 乘法指令。

#### 5. 特殊的 128 位算术（乘法和除法）

当 64 位乘 64 位的结果可能超过 64 位（即 128 位）时，或者需要用 128 位数除以 64 位数时，需要用到这些特殊指令。

* **核心寄存器**：`%rax`（存低 64 位）和 `%rdx`（存高 64 位）。

* **128 位乘法 (`mulq` / `imulq`)**
    * **输入**：一个 64 位数必须在 `%rax` 中，另一个 64 位数作为源操作数 `S`。
    * **输出**：128 位乘积存放在 `%rdx` (高 64 位) 和 `%rax` (低 64 位)。

* **128 位除法 (`divq` / `idivq`)**
    * **输入**：128 位被除数必须在 `%rdx` (高 64 位) 和 `%rax` (低 64 位) 中。除数是源操作数 `S`。
    * **输出**：**商**存回 `%rax`，**余数**存回 `%rdx`。

* **64 位除法的准备工作**：
    如果要计算 `x / y`（x 和 y 都是 64 位），被除数 `x` 只有 64 位，必须先把它扩展到 128 位（放入 `%rdx:%rax`）：
    1.  把 `x` 放入 `%rax`。
    2.  **有符号除法 (`idivq`)**：执行 `cqto` 指令。它会自动将 `%rax` 的符号位（第 63 位）复制到 `%rdx` 的所有 64 位。
    3.  **无符号除法 (`divq`)**：手动将 `%rdx` 置为 0。
